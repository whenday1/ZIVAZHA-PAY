ZIVAZHA PAY — PROTOTIPE UI

Isi:
- index.html: website responsif (bisa dibuka di Android dan desktop)
- manifest.webmanifest: metadata PWA agar dapat ditambahkan ke layar utama
- sw.js: cache dasar untuk membuka kembali prototipe saat offline

PENTING:
Ini hanya prototipe tampilan. Tidak ada backend, akun nyata, penyimpanan dana, saldo uang, QRIS aktif, top up, transfer, pembayaran tagihan, atau koneksi ke mitra. Jangan masukkan data pribadi, PIN, OTP, atau data bank.

Cara mencoba:
1. Buka index.html di browser untuk melihat tampilan.
2. Untuk menguji instalasi PWA, unggah ketiga file ke hosting HTTPS (contoh GitHub Pages).
3. Buka URL HTTPS di Chrome Android → menu ⋮ → Tambahkan ke layar utama / Install app.

Sebelum transaksi uang sungguhan:
- Bentuk dan daftarkan badan usaha sesuai model layanan.
- Dapatkan persetujuan/kontrak dari PJP atau mitra berizin yang menyediakan layanan terkait.
- Pastikan peran ZIVAZHA PAY, aliran dana, KYC, pengaduan, refund, rekonsiliasi, perlindungan data, keamanan, dan kepatuhan telah disetujui mitra/regulator.
- Bangun backend produksi, audit keamanan, dan integrasi API resmi. Jangan pernah menyimpan data kartu, PIN, OTP, atau kredensial pembayaran secara sembarangan.
